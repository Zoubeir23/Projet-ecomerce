# Frontend React - Plateforme E-commerce

Interface utilisateur moderne pour notre plateforme e-commerce multi-vendeurs.

## 🚀 Technologies

- **React 18+** avec TypeScript
- **State Management** : Redux Toolkit ou Zustand
- **Styling** : Tailwind CSS ou Bootstrap 5
- **WebSockets** : Socket.io pour chat temps réel
- **API** : Axios pour les appels API REST

## 📁 Structure

```
frontend/
├── public/                 # Fichiers statiques
├── src/
│   ├── components/         # Composants réutilisables
│   │   └── Chat/          # Composants du chatbot IA
│   ├── pages/             # Pages de l'application
│   ├── services/          # Services API et logique métier
│   ├── hooks/             # Hooks React personnalisés
│   ├── utils/             # Utilitaires et helpers
│   └── styles/            # Styles CSS/SCSS
└── package.json           # Dépendances Node.js
```

## 🛠️ Installation

```bash
cd frontend
npm install
npm start
```
